## Cross-page visual DNA

- **Shared canvas / value plan**: 近纯白画布 + 近黑墨色正文；稀缺饱和蓝（约 `#0033FF`）作 CTA / 关键词染色 / logo 点缀；深蓝色块专用于产品证据舞台。
- **Typography system**: 几何无衬线（站点用 Söhne）— 招牌式超大中等字重标题、极紧字距、章节关键词局部着色；导航与 UI 文案保持小而冷静。
- **Component / surface language**: sticky 矮顶栏；8px 级圆角主按钮；等权三栏部署卡；能力区「左真 UI / 右竖向 rail」；阴影克制，靠色块与圆角分区。
- **Imagery & evidence strategy**: 建筑/地质/雪山摄影提供气质；产品视频与 Workflow 真节点画布提供功能证明；企业 logo + 引言 + 合规章提供采购可信度。
- **Motion personality**: 极克制 — 150–200ms 色变反馈、sticky 连续、英雄视频循环；无装饰粒子/滚动劫持。签名母题是「蓝染关键词 + 深蓝产品舞台」。
- **What varies by page type**: 目前仅 marketing home。预期 docs 会降低摄影戏剧、提高阅读密度；定价页可强化三路径卡；应用 UI 不在本页范围。

## Transferable product rules

- 白纸系统 + 单一稀缺强调色；标题用「关键词染色」而非全彩标题。
- 叙事顺序：主张 → 产品舞台 → 社会证明 → 获取路径 → 能力深度 → 商业收口。
- 多部署/多套餐用等权对比卡；合规徽章贴近决策点。
- 能力深度用左证据画布 + 右章节 rail，避免首屏堆功能。
